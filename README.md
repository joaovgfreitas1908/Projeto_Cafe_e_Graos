# ☕ Café & Grãos

## 📌 Sobre o projeto

O **Café & Grãos** é um projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de criar uma aplicação web voltada à experiência e à personalização do consumo de cafés especiais.

A proposta é oferecer uma interface intuitiva, responsiva e acessível, permitindo que os usuários explorem produtos e descubram suas preferências de café.

## 🚀 Funcionalidades

- Página inicial com apresentação do projeto e carrossel de imagens.
- Tela de login com validação de campos.
- Cadastro de usuários com validações em JavaScript.
- Recuperação de senha (simulação).
- Questionário de perfil e preferências de café.
- Página de recomendações de produtos.
- Páginas de erro 403 e 404.
- Recursos de acessibilidade, incluindo ajuste de fonte e modo escuro.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- Visual Studio Code

## 📂 Status do projeto

🚧 **Em desenvolvimento**

As interfaces estão sendo organizadas e padronizadas. As próximas etapas incluem a integração entre as páginas, o processamento das respostas do questionário e as recomendações personalizadas de café.

Atualmente, as funcionalidades são demonstrativas e executadas no Front-End, sem autenticação real ou banco de dados.

## 🎓 Objetivo acadêmico

Aplicar os conhecimentos adquiridos em desenvolvimento Front-End, com foco em estruturação de páginas, estilização, interatividade, validação de formulários, responsividade e acessibilidade.

## 👨‍💻 Desenvolvimento

Projeto acadêmico desenvolvido em equipe por estudantes de Análise e Desenvolvimento de Sistemas.
